# student_management
A Web-Based Student Information Management Application

Project Overview

The Student Management System is a web-based application developed to facilitate student information management through a simple and accessible interface.

The project is being developed as part of my SIWES practical training, with a focus on applying web development concepts and database management skills.

Technologies Used

- HTML5 – Page structure
- CSS3 – User interface and styling
- PHP – Server-side programming
- MySQL – Database management
- XAMPP – Local development environment

Key Features

- Student registration
- User login and authentication
- Administrator login
- Student dashboard
- Database connectivity
- Student information management

Project Structure

The project contains PHP application files, styling resources and database-related files.

Installation and Setup

1. Install XAMPP on your computer.

2. Copy the project folder into the XAMPP "htdocs" directory.

3. Start Apache and MySQL from the XAMPP Control Panel.

4. Open phpMyAdmin.

5. Create the required MySQL database.

6. Import the provided SQL database file.

7. Configure the database connection.

8. Open the application in your browser:
   
   "http://localhost/student_management/"

Development Environment

- Code Editor: Visual Studio Code
- Local Server: XAMPP
- Database: MySQL
- Version Control: Git and GitHub
